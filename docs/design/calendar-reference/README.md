# 주간 캘린더 디자인 시안

첨부된 디자인을 참고한 독립 HTML/CSS 예제입니다. 외부 라이브러리, 폰트 CDN, 이미지 요청 없이 실행됩니다.

- `index.html`: 사이드바, 주간 시간표, 샘플 일정, 상세 팝업
- `styles.css`: 색상, 레이아웃, 반응형 화면 및 일정 시간 배치
- `script.js`: 팝업, 검색, 카테고리 필터, 메모리 내 샘플 일정 추가

세 파일을 같은 폴더에 두고 `index.html`을 브라우저로 열면 됩니다. 로컬 서버 미리보기는 `http://127.0.0.1:8092/`입니다.

색상은 CSS의 `--coral`, `--canvas`, `--ink`에서 변경합니다. 시간표 한 시간 높이는 `--hour`입니다. 각 일정의 `data-slot`에 대응하는 CSS 규칙에서 `--start`는 오전 8시 이후의 시간, `--duration`은 일정 길이입니다. 예를 들어 08:30–13:00은 `--start: .5; --duration: 4.5`입니다.

모바일에서는 주간 시간표를 가로로 스크롤합니다. 최초 상세 팝업을 닫힌 상태로 시작하려면 `#event-dialog`의 `open` 속성을 제거하세요.

시안의 날짜와 현재 시각 표시는 2023년 7월 샘플 값입니다. 서버/DB, 실제 알림, 영구 저장은 연결되어 있지 않습니다. 추가한 샘플 일정은 새로고침하면 초기화됩니다. 기존 React 서비스 화면은 교체하지 않았습니다.
