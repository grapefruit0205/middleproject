# Daylight · 팀 캘린더 미리보기

4인 팀 캘린더의 정적 웹 시안입니다. 별도 빌드 없이 HTML/CSS/JavaScript를 제공합니다.

[AWS 배포 사이트](https://main.d1za53r0rfy3x6.amplifyapp.com/)

## 가능한 기능

- 4명의 팀원 선택과 이름·역할 수정
- 현재 날짜 기준 7일 캘린더, 연·월·일 선택, 이전·다음 주와 오늘 이동
- 일정과 카테고리 관리, 수신 대상별 등록 알림 미리보기와 읽음 처리
- 반응형 메뉴, 브라우저 내 데이터 저장

## 중요한 경계

팀원 선택은 로그인이나 권한 확인이 아닙니다. 일정·프로필·알림은 같은 브라우저의 이 사이트 저장소에만 저장됩니다. 다른 기기나 다른 브라우저에는 공유되지 않습니다. 로컬 미리보기에서 입력한 데이터도 배포 사이트로 이동하지 않습니다.

이메일·푸시·예약 알림은 실제 발송되지 않습니다. 브라우저 저장소를 지우면 로컬 데이터가 사라집니다. 민감한 정보를 입력하지 마세요. 저장된 일정 자체의 수정·삭제 UI는 아직 제공하지 않습니다.

## 실행

저장소 루트에서 `python3 -m http.server 8093 --bind 127.0.0.1 --directory daylight`를 실행합니다. 포트가 이미 사용 중이면 다른 포트를 선택하세요.

`index.html`, `styles.css`, `script.js`, `team-calendar.js` 네 파일이 배포 대상입니다. `frontend/`의 기존 React 서비스나 AWS 3-Tier 백엔드를 대체하지 않습니다.

## AWS 배포

AWS Amplify Hosting, 서울 리전의 `daylight-team-calendar` 앱에 수동 배포합니다. 기존 아키텍처 안내 사이트는 별도 앱으로 유지합니다. 자동 Git 배포는 연결하지 않았습니다.

승인된 AWS CLI 프로필과 대상 계정을 명시하여 저장소 루트의 `scripts/deploy-daylight.py`를 실행할 수 있습니다. 스크립트는 지정 계정 일치를 확인하고 위 네 파일만 묶어 업로드하며, 자격 증명이나 업로드용 서명 URL을 출력하지 않습니다. 출력 상태는 배포 시작 상태이므로 AWS에서 해당 작업의 `SUCCEED`를 별도로 확인해야 합니다. 사용량에 따라 AWS 요금이 발생할 수 있습니다.

## 다음 구현

인증된 팀 멤버십 → 서버의 팀·일정·수신자 저장 → 비동기 이메일 처리 → 수신자별 발송 상태 연결이 필요합니다. 기존 백엔드의 SES 발송 코드는 확장 지점이며, 이 정적 시안에는 연결되지 않았습니다.
